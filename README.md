# 🌲 紫荆长河 Zijing Long River


> 一条河流，记录一片森林的生命。


紫荆长河是一个基于 WebGL 与 Three.js 创建的沉浸式森林生态展示网页。

项目模拟了一片巨大森林中的自然河流环境，通过动态水面、森林植被、鱼群和动物系统，打造一个在线探索的数字生态世界。


---

# 🌊 项目展示


紫荆长河包含：

- 🌲 巨型森林环境
- 🌊 动态流动河流
- 🐟 鱼群游动系统
- 🌱 水草生态系统
- 🦐 河底动物模拟
- ☀️ 昼夜循环
- 🌧 天气效果

# ✨ 功能特点


## 🌲 森林系统

- 随机生成森林树木

- 自然生态布局


## 🌊 河流系统

- 白天与夜晚变化
- 光照变化
- 雨滴天气效果


## 🦐 动物系统

- 河底动物生成
- 自动移动
- 生态循环

# 🎨 项目理念


自然并不是静止的画面。

森林、河流、动物共同组成一个持续变化的生命系统。

紫荆长河希望通过数字技术，让每个人都能在线感受自然生态之美。
